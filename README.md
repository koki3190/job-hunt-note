## ✨ 主な機能

| | 機能 | 内容 |
| :---: | --- | --- |
| 🏢 | 企業リスト | 企業名・勤務地・給与・福利厚生・メモを登録、編集、削除 |
| 📋 | 選考状況 | 応募・面接・内定などの進捗を管理 |
| 🗓️ | 面接スケジュール | 次の面接日時を日本時間で登録して一覧表示 |
| 🔎 | 検索と絞り込み | 企業名・勤務地の検索、選考状況の絞り込み、並び替え |
| 📊 | ダッシュボード | 登録企業・選考中・これからの面接・内定を集計 |
| 💾 | バックアップ | JSONファイルへの書き出し・読み込み |

## 🚀 使い方

1. **[就活ノートを開く](https://koki3190.github.io/job-hunt-note/)**
2. 「企業を追加」から、気になる企業の情報を登録
3. 「編集」で選考状況と次の面接日を更新
4. 「面接スケジュール」で予定を確認
5. 「使い方・保存」からバックアップを保存

> 公開URLが404になる場合は、リポジトリの Settings → Pages で main / (root) からの公開を設定してください。

## 🛠️ 技術と工夫

- HTML / CSS / JavaScriptで構成した、インストール不要のWebアプリ
- localStorageによるブラウザ内保存
- 日本時間での面接日時管理
- 入力文字数・日時・バックアップ形式の検証
- 保存失敗時の案内とバックアップ機能
- スマートフォン向けのレスポンシブ表示

## 💻 ローカルで起動

Code → Download ZIPからダウンロードし、展開後の `index.html` をブラウザで開きます。

## 📝 データについて

入力内容は各自のブラウザに保存されます。サーバーへの保存や端末間の自動同期はありません。ブラウザのサイトデータ削除に備えてバックアップを保存してください。

初期登録された3社の企業情報は**2026年10月17日時点の参考情報**です。現在の条件は各社の情報源で確認してください。個人の面接日時は初期登録されていません。
